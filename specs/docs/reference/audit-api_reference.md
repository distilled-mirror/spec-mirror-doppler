# Audit API Reference

You can view the general instruction for how to use our API in our [API Reference](https://docs.doppler.com/reference/api) documentation.

## Audit API

Doppler's audit API is built for partner integrations that would like to get information out of Doppler for audit purposes.

This is a read-only API and can only be used with an "Audit API Token". This token read-only and restricted to a single workplace.

## Get an audit token

Note that only workplace owners are allowed to manage audit tokens. To get an audit token:

1. Go to the Doppler dashboard.
2. Click on the **Tokens** in the menu on the left.
3. Click on the **Audit** tab.
4. Copy the token to your clipboard.
